# BioBCD - Banco de Dados

Este repositório foi desenvolvido para centralizar a modelagem e os scripts. O objetivo principal é organizar todas (ou quase) estruturas aprendidas ao longo dos dias nas aulas de Banco de Dados.

---

📚 Objetivos de Estudo

O conteúdo aqui presente foca na aplicação prática de conceitos fundamentais, tais como:

- Modelagem de Dados: Criação de diagramas Entidade-Relacionamento (DER) para traduzir problemas de negócio em estruturas lógicas.

- Linguagem SQL (DML/DDL): Escrita de scripts para criação de tabelas, inserção de dados e consultas complexas.

- Gerenciamento de Integridade: Aplicação de chaves primárias (PK), chaves estrangeiras (FK) e restrições (Constraints).
